Fonte original e aviso de não equivalência entre leitura e domínio mantidos. Não se inventam vínculos com jurisprudência/questões para capítulos sem relação conferida.
- CSS ameixa/marfim, fonte relativa nos livros para permitir zoom, controles de toque. Sem mudanças em HTML, corpus, textos dos capítulos, motores pedagógicos, IDs, contratos de persistência, backup ou gabaritos. Nenhuma mudança em dados privados.
